MIDI to PT

Ableton Live doesn't write the tempo into the MIDI files it exports, so Pro Tools reads them at 120 BPM. This page adds the right tempo and merges all your tracks into a single file. Free, no sign-up. Nothing is uploaded: everything happens in your browser.

1Files

File Notes Length Start Tempo found Remove

“Start” is the bar where the clip began in Ableton. If a clip didn't start at bar 1, enter its bar here: no need to consolidate.

2Tempo

/

The exact BPM of your Ableton set, decimals included (92.5 for example). Fixed tempo only: tempo changes are not carried over.

3Download

One .mid file with every track and the tempo. If you also need each track on its own, they come together in a .zip.

In Pro Tools

  1. File › Import › MIDI, then choose the multitrack file.
  2. Destination New Track, location Session Start.
  3. Tick Import Tempo Map From MIDI File. This time the file carries the right tempo: Pro Tools sets the session to it and creates one track per instrument.
